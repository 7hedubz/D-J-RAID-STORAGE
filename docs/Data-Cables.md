# Data Cables

Cables form a **persistent graph** (SavedData). Paths work through unloaded chunks. WorldEdit that deletes blocks without events can desync it.

## Attach rules

- RAID Chassis and CHEST: **back** face only.
- HOPPER: RAID-in on the **right**, visual arm also on the **left** output.
- Vanilla inventories: chests, barrels, shulkers, hoppers, furnaces, brewing stands, dispensers, crafters — except furnace / smoker / blast furnace **bottom** (use a hopper there).

Recipe: string corners, iron **ingots** top and bottom middle, copper **ingots** in the center row → 8 cables.
