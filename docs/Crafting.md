# Crafting

- **Chassis:** 8 stone + iron ingot center
- **Stone CHEST:** 8 cobblestone + iron ingot center
- **Data cable:** string corners, iron ingots top/bottom middle, copper ingots center row → 8
- **HOPPER:** 8 emeralds around a vanilla hopper
- **Upgrades:** 8 of the resource + redstone center, **except Netherite**
- **Netherite upgrade:** smithing table — Netherite Upgrade template + Amethyst CHEST Upgrade + Netherite Ingot

Apply upgrades in order with sneak-right-click on a placed CHEST, or shapeless-craft a lower CHEST with every kit in between (stone + all kits through diamond → diamond CHEST, without placing it). No shapeless path to Admin CHEST.

All RAID blocks are pickaxe-mineable.
