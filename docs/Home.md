# D&J RAID Storage

NeoForge **26.3** (`26.3.0.95`) mod. Digital storage without all that energy stuff.

A **RAID Chassis** stores digitized items. **CHEST** terminals browse that storage over **data cables**. A **HOPPER** filters and extracts into nearby inventories.

| Acronym | Stands for |
|---|---|
| RAID | Ridiculous Amount of Item Data |
| CHEST | Console for Handling Encoded Storage Transactions |
| HOPPER | Hardware Output Port for Payload Extraction and Routing |
