# Terminal

AE2-style CHEST GUI: search, grouped grid, capacity bar.

## Clicks

| Click | Result |
|---|---|
| Upper panel while holding an item | Digitize (remainder stays in inventory) |
| Shift-click player inventory | Digitize |
| Left-click stored item | 1 into inventory |
| Shift-left stored item | One full stack into inventory |
| Right-click stored item | Every matching item until inventory is full |

Search stays clickable after picking a result. Counts use a smaller overlay and k/M for large stacks.

## Groups

Headers never say “Blocks”:

Building, Decoration, Natural, Crafting, Functional, Redstone, Ores, Ingots, Gems, Tools, Combat, Farming and Food, Ingredients, Enchanted Books, Spawn Eggs, then one header per non-vanilla mod (including RAID), then Other.

Notable placements:

- Flower pots, decorated pots, potted plants, banners → **Decoration**
- Iron / gold / copper / netherite **blocks** → **Ingots**
- Diamond / emerald / lapis / amethyst / quartz **blocks** → **Gems**
- Doors and boats → **Functional**
- String → **Ingredients**
- Enchanted books → their own group
